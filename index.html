Need to know

Frequently asked questions

Voice aur audio export ke baare mein important information.

Kya yeh tool Urdu text ko read kar sakta hai?

Haan, agar aapke device par Urdu voice maujood ho. Language list mein Urdu select karein.

Urdu voice list mein nazar na aaye to?

Chrome ya Edge use karein. Android par Google Text-to-speech mein Urdu voice install karein, phir page refresh karein.

Kya download ke liye key chahiye?

Nahi. Audio download bilkul free hai, kisi bhi key, signup ya server ke bagair — awaz seedha aapke browser ke andar AI model se banti hai.

Pehli dafa download mein time kyun lagta hai?

Pehli baar ek chhota voice model (~85MB) load hota hai. Uske baad wo aapke browser mein save rehta hai aur agli baar turant, bina internet ke bhi, kaam karta hai.

Kya mera text private rehta hai?

Haan, hamesha. Playback ho ya download, text kabhi kisi server ko nahi bheja jata — sab kuch aapke device par hota hai.

Use responsiblyYeh tool voice testing aur content preparation ke liye hai. Passwords, private documents ya financial details enter na karein.
