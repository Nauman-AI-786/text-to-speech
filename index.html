Urdu ya Hindi ki MP3 kaise banaun?

"Natural" tab chunein, Language mein Urdu ya Hindi rakhein, text likhein aur Generate audio dabayein. Audio ban kar neeche aa jati hai, wahan se Download karein. Text Urdu ya Hindi mein ho to language khud badal jati hai.

Browser tab mein download kyun nahi hota?

Browser tab aapke device ki awaz se live sunata hai, file nahi banata. Download ke liye Natural ya Offline tab use karein. Browser tab mein Urdu sunne ke liye device par Urdu voice honi chahiye (Chrome/Edge; Android par Google Text-to-speech mein Urdu install karein).

Offline tab kya hai?

Ye sirf English ke liye hai. Pehli baar ek chhota voice model (~85MB) download hota hai, uske baad internet ke bagair chalta hai. Is se WAV file banti hai.

Kya mera text private rehta hai?

Offline tab mein text device se bahar nahi jata. Browser tab mein bhi aam taur par nahi, lekin Chrome ki kuch "Google" voices online ho sakti hain. Natural tab mein text awaz banane ke liye is site ke backend server ko bheja jata hai, is liye passwords ya private documents na likhein.
